# LearningCore

macOS IME向けのローカル学習データ管理層。Swift/Foundation/CryptoKitのみを使用し、ネットワーク処理はありません。

## 検証

```sh
swift run LearningCoreChecks
```

Command Line ToolsにSwift Testingがないため、debug実行形式で6シナリオを検証します。releaseではpreconditionが無効になる最適化設定があるため、この検証をuncheckedビルドで実行しないでください。

## 境界

入力収集、傾向抽出器、変換エンジン、IME、UI、定期削除タイマーは未実装。呼出側は起動時・処理前に加えて定期的にpurgeExpiredを呼ぶ必要があります。期限の変更を伴わない再試行、期限切れ結果の棄却、削除時の世代変更による古い結果の棄却を実装しています。

単一プロセス・単一LearningStore所有を前提とします。同じ保存先を複数インスタンスで同時利用しないでください。原文は私有ディレクトリのJSON内に保存し、保存権限はディレクトリ0700・ファイル0600です。暗号化や物理消去、バックアップ制御は実装していません。正常抽出時と期限切れ時はJSONから除去します。

暫定値は要件定義書に記録。学習元不明は貼り付けと同じ弱い根拠に扱い、表記の学習には使いません。貼り付けのハッシュは重複抑制目的のみで直近256件まで保存し、編集・削除時に破棄します。ハッシュは匿名化の保証ではありません。自動抽出とIME接続後に学習効果と実機性能を評価する必要があります。
